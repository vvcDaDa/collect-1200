## 🚀 发布到 GitHub Pages 指南

本项目采用 **零外部依赖纯静态架构**（内置 `.nojekyll` 与官方 `.github/workflows/pages.yml`），所有资源均为相对路径 `./`，可直接构建部署至 `https://<用户名>.github.io/<仓库名>/`。

### 1. 推送代码到 GitHub
```bash
git init
git add .
git commit -m "feat: 2.5D graphics & PC experience upgrade for FriedRich (Freddy)"
git branch -M main
git remote add origin https://github.com/<你的用户名>/<你的仓库名>.git
git push -u origin main
```

### 2. 开启 GitHub Pages（两种方式任选其一）
- **方式 A：GitHub Actions 构建（推荐）**  
  进入仓库 **Settings → Pages**，将 **Build and deployment → Source** 设为 **`GitHub Actions`**，内置工作流会自动完成构建与发布。
- **方式 B：分支直接构建**  
  进入仓库 **Settings → Pages**，保持 **`Deploy from a branch`**，选择 `main` 分支与 `/ (root)` 保存即可。
