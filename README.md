# 🎯 拯救 FriedRich：2.5D 城市反诈打工大作战

> **灵感来源**：QQ 群友 **FriedRich (Freddy)** 误信网络兼职刷单被骗走 ¥1,200（名字带 *Rich*，结果直接被骗子 *Fried* 炸糊了 😂）。  
> 本作是一款面向 **电脑键鼠深度优化**（同时自适应手机触屏）的 **2.5D 城市街区打工 & 反诈动作收集网页游戏**，包含两幕跌宕起伏的 **剧情模式** 与挑战极限的 **无尽模式**！

---

## 🎮 双模式玩法设计

### 📖 1. 剧情模式（两幕完整战役）
- **第一阶段（凑齐 ¥1,200）**：初入四大街区，通过捡瓶子/易拉罐/纸箱、跑跨区外卖、蹲日结兼职圈、抢群红包积少成多，击败 **【金牌派单总监·杰克导师】** 凑够 ¥1,200。
- **突发连环骗局转折**：刚攒够 ¥1,200 的 Freddy 轻信客服“做完最后一联单全额提现”，结果连本带利再被卷走 **¥12,000**！
- **第二阶段（觉醒追回 ¥12,000）**：Freddy 彻底醒悟，解锁全城高薪跨区跑腿、CBD 驻场兼职与专案组悬赏，依次迎战三大电诈头目并最终赚回 **¥12,000** 完美翻盘！

### ♾️ 2. 无尽模式（生存冲榜挑战）
- 无金额上限！随存款攀升，四大电诈头目轮番狂暴降临，10 种群友外援神装支持无限进修叠层，独立记录本机 **无尽最高存款** 与击败头目数。

## 👑 四大电诈头目 Boss

1. **【金牌派单总监 · 杰克导师】**：脚踩霓虹平衡车，甩出金色假合同飞牌并发动三连折线突进。
2. **【AI 拟声千面客服 · 魅影姬】**：环绕四色直播环灯，可瞬移并召唤全息诱饵分身，发射螺旋声波弹幕。
3. **【黑客洗钱巨兽 · 冻结者 404】**：四足重装蜘蛛机甲，铺设高压账户冻结电网并发射追踪冻结飞弹。
4. **【境外刷单总庄家 · 王总】**：胸嵌 `[诈|骗|局]` 三轴老虎机的黄金赌城机甲，发动筹码风暴与王座冲撞。

## 🚀 发布到 GitHub Pages

本项目为 **零外部依赖纯静态网页**（已配置 `.nojekyll` 与 `.github/workflows/pages.yml`），所有路径均采用相对路径 `./`。

1. 推送全部代码至 GitHub 仓库（`main` 分支）。
2. 进入仓库 **Settings → Pages**，在 **Source** 中选择 **`GitHub Actions`**（或保持 `Deploy from a branch` 指向 `main` / `/ (root)`），等待构建完成即可通过生成的网址游玩并分享到 QQ 群！
